Microservices Architecture

This Angular app communicates exclusively through the API Gateway

device_hub Service Registry Port 8761 — Eureka Server

Netflix Eureka discovery server. All microservices register here on startup. Start this first.

 router API Gateway Port 8765 — Spring Cloud Gateway

Single entry point for Angular. Routes /question-service/** and /quiz-service/** via Eureka.

 help Question Service Port 8080 — MySQL: quizapp

Stores questions and categories. Scores answers. Exposes 6 REST endpoints.

 assignment Quiz Service Port 8090 — MySQL: quizdb

Manages quiz lifecycle. Uses OpenFeign to call Question Service for random questions.
